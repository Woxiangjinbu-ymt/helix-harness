## Coding 工作台与工具

### AC01 · 默认工作台与仓库绑定

对应需求 F1、F2。取证任务 T138。

- **验证方式**　从默认地址进入工作台。在有未提交修改的仓库 A 建会话、读出该修改并留一段草稿。逐一开合文件、Diff、终端和工具详情，访问设置与 RSI Center。在 B 建第二个会话，从最近会话重开 A，再临时移走验收用的 A 并尝试执行。
- [ ] **通过条件**　首屏可直接编程。开合详情后草稿逐字相同。A、B 显示各自的实际目录。A 被移走后仍可看历史，页面说明目录不可用，新操作被阻止，B 与备用目录均无该次写入。
- **保留证据**　两个会话 ID、实际目录、A 中未提交内容的识别标记，以及移走 A 后的提示和 B 的前后差异。

### AC02 · 真实模型多轮编程与续聊

对应需求 F3、F4、F5、F7、F11。取证任务 T224、T511。

- **验证方式**　在普通 Coding 工作台选择含已知失败测试的仓库。让真实模型运行测试并解释失败，再追问“修复刚才的问题并重跑”。关闭全部工作台页面，从历史重开原会话，询问修改位置。最后在同一工作树独立重跑该测试。
- [ ] **通过条件**　首轮结束前能看到增量文本。两轮的调用记录给出同一测试先失败、后通过的输出和退出状态。页面 Diff、磁盘文件与 Git 差异一致，独立重跑通过。重开后能指出这次改动的文件和内容。
- **保留证据**　`session_id`、各 `turn_id`、实际 Provider 与模型、首个文本事件及轮次终态的顺序、工具记录、两次测试输出、Git 差异和独立重跑结果。

### AC03 · 文件操作、Git 差异与改动归属

对应需求 F4、F7。取证任务 T138。

- **验证方式**　在临时仓库留下用户已暂存和未暂存的两处修改。分别按文件名和内容搜索并读取命中项，让 Agent 新建、编辑和删除文件，再用编辑器修改同轮已编辑的文件，制造来源混合的差异。
- [ ] **通过条件**　列表、搜索命中和读取结果与磁盘相符。逐文件对照 `git status --short`、`git diff --cached`、`git diff` 和新增文件字节，总览包含用户原有改动。本轮摘要中确定归属的修改有调用依据，混合且无法确定的部分有明确标记。
- **保留证据**　操作前后的 Git 状态、两类 Diff、新增文件摘要，以及本轮变更到工具调用的对应关系。

### AC04 · 并行工具时间线与终端结论

对应需求 F5、F6。取证任务 T138。

- **验证方式**　通过实际 Runtime 并行发出两个同名读取，参数含不同文件标记，让其中一个读取失败。分别运行有、无可展示思考事件的样例，再执行一个只有普通输出、缺少可靠测试结论的命令，展开完成摘要。
- [ ] **通过条件**　每张工具卡只关联自身的参数、权限决定、输出或错误，完成顺序反转时仍正确。有可展示思考事件的轮次才出现相应区块。终端显示实际目录、命令与输出，测试结论为“未知”。摘要内的变更、测试和未完成事项都可回到本轮证据。
- **保留证据**　原生事件的公开类型与顺序、两个调用 ID、对应卡片及终端记录。思考区块只核对事件是否出现。

### AC05 · 按调用授权与沙箱

对应需求 F8、N9。取证任务 T138、T221。

- **验证方式**　在需询问的模式下刷新待授权页面，依次做本次允许、标示范围内的持续允许和带反馈拒绝。用范围外的另一目标再次发起调用。再测试策略直接拒绝、其他会话或取消后的旧答复、不受信的浏览器来源，以及要求的沙箱不可用。
- [ ] **通过条件**　等待时目标文件保持原值。本次允许仅执行原调用一次，持续允许只在所示范围生效。拒绝反馈进入对应结果，直接阻止时显示原因。跨会话、旧答复及不受信请求均被拒，必需沙箱不可用时显示错误且未启动命令。
- **保留证据**　授权 ID 与调用 ID、决定的范围与反馈、拒绝响应、目标前后摘要及命令启动计数。

### AC06 · 同一工作树的写入权与外部编辑

对应需求 F9、N7。取证任务 T138、T221。

- **验证方式**　两个会话分别通过真实路径和别名打开同一工作树。A 启动会持续写入的命令，B 尝试查看文件、编辑和执行写命令。等 A 的写进程退出后再由 B 重试。另外让 Agent 读文件后从外部编辑器改动，再请求编辑。
- [ ] **通过条件**　A 持有写入权时 B 可读，两种写请求均显示持有会话，磁盘只有 A 的预期改动。写进程退出并释放后 B 重试成功。发生外部修改时，重新读取先于下一次编辑，用户的新内容被保留或冲突由用户明确处理。
- **保留证据**　两个会话的实际工作树、占用响应、许可释放与写入时序、外部改动前后内容以及重读事件。

## 会话稳定性、恢复与配置

### AC07 · 取消、清理与写入权交接

对应需求 F10、N4。取证任务 T203、T204、T509。

- **验证方式**　分别在等待权限时和运行父子写进程时从 Web 取消。让清理延迟到超时提示可见。旧答复再次到达时，另一会话同时尝试写入。清理完毕后由另一会话重试，原会话再开一轮。
- [ ] **通过条件**　两种起始状态均可观察到“取消中”，旧授权失效，受理取消后没有新工具派发。清理逾期显示阻塞原因，期间写入权仍受保护。核对所属父子进程与临时资源已回收、输出停止变化后，才显示“已取消”并可交接。取消前落盘的修改可查，原会话可继续。
- **保留证据**　取消受理与终态的事件、进程启动身份和退出记录、清理前后写入尝试、最后一次磁盘修改及后续轮次 ID。

### AC08 · SSE 两次重连与失效游标

对应需求 F6、F11、N2。取证任务 T207、T222。

- **验证方式**　在含增量文本、工具、授权和终态的普通轮次中断开事件流两次。第一次在执行中重连，第二次让轮次在断线期间完成再重连。另用失效的续读位置打开同一会话。
- [ ] **通过条件**　断线时已显示内容保留并提示断线。正常重连补回遗漏事件，失效位置从持久视图重建后继续订阅。按消息标识合并片段、按调用标识配对工具后，与同次服务端记录逐项比对，既无重复或遗漏，文本、工具、决定和终态的顺序也一致。测试文件的副作用计数为一。
- **保留证据**　两次断开前最后已应用的位置、重连及重建后的事件序列、同一会话的服务端序列和副作用计数。

### AC09 · 真实压缩边界与恢复后的模型输入

对应需求 F11、F14、N5。取证任务 T211、T222。

- **验证方式**　在测试对话早期和近期分别放入可识别的事实，让长对话实际触发原生压缩。在压缩后再发一轮，关闭页面并重启服务。从原会话追问早期事实和近期细节，同时比对压缩后及恢复后的模型请求。
- [ ] **通过条件**　历史仍能查看压缩前的消息与压缩通知。恢复输入含同一摘要、应保留的近期消息和边界后新增的消息，各出现一次。已压缩的原始前缀没有重复送入。恢复后的回答能引用两个事实。
- **保留证据**　压缩边界及摘要标识、受控样本消息的顺序与出现次数、脱敏的请求比对结果及恢复后的轮次记录。

### AC10 · 服务中断后识别未知结果

对应需求 F10、F11、N5。取证任务 T209、T222。

- **验证方式**　先完成一轮作为对照。下一轮让写命令追加一次可计数的磁盘标记，在追加后、工具结果落盘前中断验收后端。重启，重开同一会话并刷新两次，检查 Diff 后由用户提交新一轮。
- [ ] **通过条件**　已确认保存的消息、调用、权限决定与先前结果均可查，对照轮次仍已完成。失联轮次为“中断”，这次调用为“执行结果未知”。Diff 能看到标记，重启和刷新后计数始终为一，只有用户提交后才产生新轮次。
- **保留证据**　对照及中断的轮次 ID、中断位置、重启前后已保存事件、Diff、标记计数与新轮次 ID。

### AC11 · Provider 切换、生效时间与来源

对应需求 F12。取证任务 T213、T214、T227。

- **验证方式**　在设置中保存两份受支持的 Provider 配置，用 A 开始一轮，运行中为下一轮选 B。再用错误配置发起真实请求，并显式运行一次演示 Provider。重新打开设置和前一轮历史。
- [ ] **通过条件**　保存后设置仅展示掩码或已配置状态。两轮实际请求分别使用 A、B 的 Provider 和模型，原轮次历史仍显示 A。错误请求显示所选真实 Provider 及原因，演示运行明确标注来源。
- **保留证据**　两轮快照和请求的非秘密身份、错误所属轮次、演示来源及设置回读结果。

### AC12 · Skills、MCP 与 Hooks 的实际行为

对应需求 F13。取证任务 T215、T216、T217、T227。

- **验证方式**　从工作台列出并加载带识别行为的 Skill，连接本地测试 MCP 服务、调用工具并断开，执行已配置 Hook。另开未配置此 Hook 的会话，分别制造 Skill 加载及 MCP 连接失败。
- [ ] **通过条件**　所选 Skill 的加载与实际行为可回查。MCP 连接状态和工具可用性随连接及断开变化，调用返回服务标记。Hook 结果仅出现在目标会话，加载或连接失败均显示扩展来源和具体原因。
- **保留证据**　会话的扩展选择、Skill 行为、MCP 调用与返回标记、Hook 事件及两个故障的结果。

### AC13 · 实际满 30 分钟的关页长任务

对应需求 N1、F10。取证任务 T225、T226、T509。

- **验证方式**　为一项本地任务设置超过 30 分钟的执行预算，安排一段静默期和一段较长输出。记录服务端开始时间与轮次 ID，切换会话，关闭全部应用页面。用同一入口重新打开原会话查看进度，待该任务实际运行满 30 分钟后从 Web 取消。
- [ ] **通过条件**　以同一任务服务端的运行开始时间与取消受理时间相减，差值 **至少 1800 秒**。关页前后轮次和调用标识相同，可见关页期间产生的进度。长输出可分段查看或明确标注截断，命令与最终状态可查。按 AC07 核对取消清理和写入权交接。
- **保留证据**　开始与取消受理的服务端时间、计算得到的秒数、全部页面关闭和重开的时间、离线期间的进度、同轮的输出与清理记录。

## RSI 评测、版本与历史

### AC14 · 题集分类与多题多次评测

对应需求 F15、F16。取证任务 T310、T323、T406。

- **验证方式**　在 RSI Center 浏览正式题、公开示例和待审核候选，核对题面及版本。选择已有冻结 Benchmark、被测 Provider 与模型、Harness 快照和预算，运行多题、每题多次，制造一次可识别的单题中断。
- [ ] **通过条件**　三类材料可区分，正式评测只接受适用的冻结版本。逐题逐次核对实际运行次数、状态、模型、快照和独立实验目录。中断可定位到具体一次运行，其他已完成结果仍可查，普通工作树无实验写入，历史分数仍指向原冻结题集。
- **保留证据**　冻结题集版本、实验 ID、逐题的运行序号与配置、工作树前后状态和历史成绩引用。

### AC15 · 独立评分、公开轨迹与封存产物复算

对应需求 F17。取证任务 T308、T309、T323。

- **验证方式**　从已评分的单题进入公开轨迹、工具结果、封存代码与 Evaluator 回执，选择同一产物和对应的冻结裁判复算。再打开一个仅运行公开测试的示例。
- [ ] **通过条件**　公开事件次序和工具结果属于这次单题，代码产物身份与原回执相符。复算的新回执可与原件并列核对，裁判、产物依据及分数一致，原件仍可读。正式分数均能打开独立回执，公开示例只展示有依据的公开测试结果。
- **保留证据**　单题 ID、产物和裁判摘要、原回执、复算回执及字段比对结果、公开示例的结果视图。

### AC16 · 失败分析、策略差异与版本晋升

对应需求 F18、F19。取证任务 T313、T314、T321、T512。

- **验证方式**　在独立可写谱系运行既有进化流程，取得一次接受和一次拒绝。可用标明来源的受控模型稳定复现两种决定，执行、评分与版本提交均走实际路径。从失败结论回到原轨迹，并从封存的父子快照和回执独立复核成绩。
- [ ] **通过条件**　失败结论能定位到样本和轨迹，优化假设及 Prompt、Skills 或 Workflow 的差异与快照相符。用回执按每题多次取平均、各题等权汇总，可还原两版成绩、模型和样本数。接受后活动引用前移，拒绝后仍指向该父版本，候选与报告可查。运行前后 Runtime 源码摘要一致。
- **保留证据**　谱系 ID、两次决定、父子策略摘要、失败证据位置、逐题回执与复算表，以及 Runtime 前后摘要。

### AC17 · 主动回滚的权限、竞争与原子性

对应需求 F20、N12。取证任务 T318、T319、T320、T323。

- **验证方式**　选一条可写谱系和其中先前接受的目标，保留已启动的实验。以有权限的操作者预览并确认回滚，再启动选择当前活动版本的新实验。用副本测试两次基于同一旧引用的版本变更，并分别在决定提交前、提交后应答前中断服务。另试只读归档、跨谱系和未接受目标。
- [ ] **通过条件**　预览显示当前与目标版本。成功后仅一条主动回滚决定，引用与新修订相符。已启动任务按原快照运行，新实验按回滚后引用运行。并发变更至多一个成功，冲突方可见最新引用。重启后只可观察到完整旧状态或完整新状态，重送能找回已提交的同一决定。无效目标被拒，活动引用及只读归档内容保持原值。
- **保留证据**　原引用、目标、修订和决定 ID，竞争双方回执，每个中断点恢复后的引用与决定，两个实验的实际快照及归档摘要。

### AC18 · 历史指标的来源、分母与缺项

对应需求 F21。取证任务 T322、T513。

- **验证方式**　按原标识重开有真实模型和演示来源的历史实验。选择一组记录完整、一组缺少用量或费用的运行，按页面注明的轮次、样本范围和成功率口径，从回执、用量及时间记录独立计算。
- [ ] **通过条件**　每轮模型来源和版本与归档一致。样本数及成功率分子、分母可复算，Token、耗时、已记录费用与同组原始记录在页面显示精度内相符。缺失值显示“未记录”，已记录的零值可区分。
- **保留证据**　历史实验与版本标识、样本集合、统计口径、独立计算值与页面值、缺失字段及来源。

## 架构隔离与跨模块操作

### AC19 · 两种业务独立运行与三任务隔离
